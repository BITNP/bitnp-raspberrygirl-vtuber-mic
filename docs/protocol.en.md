# Protocol Subset

Mic is a hub client, not a peer service. Set `ORCHESTRATOR_REPO` to an Orchestrator checkout and read its local canonical contracts at `$ORCHESTRATOR_REPO/schemas/protocol/envelope.schema.json` and `$ORCHESTRATOR_REPO/schemas/protocol/event-data.schema.json`. Mic participates in its control and RTP media subset only. It does not copy schemas or fixtures.
